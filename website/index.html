MindLane

An AI-powered desktop mind-mapping app.
Turn ideas, documents, and conversations into living mind maps.

Get started on GitHub Explore features

Features

Everything is built on a local-first canvas with an AI assistant that works alongside you.

AI Generation & Chat

Describe what you're thinking in the floating chat panel and watch a mind map grow on the canvas. The assistant streams its progress live, and keeps refining the map — adding branches, restructuring nodes, answering questions.

Documents to Mindmap

Drop in what you already have and get a structured map back. Deterministic batched extraction with live per-stage progress — reading, extracting, merging, finalizing.

Canvas Editing

A fast, free-form canvas built on React Flow. Restyle nodes in the style panel, auto-layout when things get messy, and drive everything from the keyboard.

Multi-Provider

Bring your own API key — switch providers without changing how you work.

Memory Palace

Turn a selected branch into an illustrated palace story — an image for every stop along the route, powered by providers with vision and image generation.

One input, many sources

Attach files or paste a link — the assistant reads and structures them for you, no manual mapping.
